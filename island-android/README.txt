ISLAND ДЛЯ ANDROID
==================

Что это: остров сверху экрана, как динамический остров. Показывает плеер (обложка, название,
слова песни с подсветкой, перемотка, пауза, вперёд/назад), уведомления, громкость, яркость,
зарядку, Wi-Fi, Bluetooth, часы когда музыка не играет, заметки («Карман»), быстрые действия.

КАК ПОЛУЧИТЬ APK (способ 1, без установки программ: через GitHub)
1. Зарегистрируйся на github.com (бесплатно) и создай новый репозиторий (New repository, любое имя).
2. Распакуй этот архив. В репозитории нажми "uploading an existing file" и перетащи ВСЁ содержимое
   распакованной папки (вместе с папкой .github и файлами gradlew, gradle, app). Нажми Commit changes.
   Если папка .github не загрузилась: Add file > Create new file, имя  .github/workflows/build.yml
   и вставь туда содержимое файла build.yml из архива.
3. Вкладка Actions > "Build APK" > дождись зелёной галочки (3-6 минут).
4. Открой этот запуск, внизу "Artifacts" > Island-apk. Скачается zip, внутри app-debug.apk.
5. Если сборка красная: открой её, скопируй текст ошибки и пришли мне, я исправлю.

СПОСОБ 2: Android Studio
Файл > Open > выбери эту папку > подожди синхронизацию > Build > Build APK(s).
APK лежит в app/build/outputs/apk/debug/app-debug.apk

КАК УСТАНОВИТЬ И ЗАПУСТИТЬ
1. Скопируй app-debug.apk на телефон, открой его, разреши "установку из неизвестных источников".
2. Открой Island. Нажми по порядку:
   - "Ограниченные настройки": О приложении > три точки справа вверху > "Разрешить ограниченные
     настройки" (Android 13 и новее; без этого переключатель уведомлений серый).
   - "Доступ к уведомлениям": включи Island.
   - "Поверх других окон": включи Island.
3. Остров появится сверху. Кнопка "Тест уведомления" покажет, как он выглядит.
   Отступ сверху регулируется в настройках (чтобы не накрывать камеру).

УПРАВЛЕНИЕ
- Нажатие на остров: раскрыть плеер. Нажатие вне острова или крестик: свернуть.
- Долгое нажатие: настройки.
- "Действия": фонарик, звук, калькулятор, камера, Wi-Fi, настройки.
- "Карман": заметки. Нажатие на заметку копирует, долгое нажатие удаляет.
- Плитка "Остров" в шторке быстрых настроек: скрыть / показать остров.

ЧЕМ ОТЛИЧАЕТСЯ ОТ ВЕРСИИ ДЛЯ WINDOWS
- Уведомления и плеер читаются штатно, без UI Automation: надёжнее.
- Эквалайзер анимированный (Android не даёт слушать звук других приложений).
- Нет: Caps/Num Lock, камера/микрофон, горячие клавиши, перетаскивание файлов, история буфера
  обмена, скриншоты и загрузки (Android не позволяет приложениям в фоне это делать).
- Слова песен только с lrclib.net (без запасного NetEase).
